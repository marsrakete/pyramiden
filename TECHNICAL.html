Kegelschnitt: Herleitung der Ellipse

Die Berechnung in ellipse/geometry.js verwendet keine nachträgliche Annäherung. Jeder Kurvenpunkt entsteht direkt aus derselben Kegelgleichung und Ebenengleichung.

1. Kegel und Schnittebene

Für die feste Kegelgeometrie gelten Höhe \(H=5\), Radius \(R=3\) und damit \(k=R/H=3/5=0{,}6\):

\[x^2+z^2=k^2y^2\]

Mit Neigung \(\alpha\) und Mittelpunktshöhe \(h\) berechnet der Code zunächst:

\[m=\tan(\alpha)\]

Die Schnittebene lautet daher:

\[y=h+mx\]

2. Einsetzen in die Kegelgleichung

Wir ersetzen \(y\) durch \(h+mx\):

\[x^2+z^2=k^2(h+mx)^2\]

Das Quadrat wird ausmultipliziert:

\[(h+mx)^2=h^2+2hmx+m^2x^2\]

Nach dem Einsetzen und Verschieben aller Terme auf die linke Seite:

\[(1-k^2m^2)x^2-2k^2hmx+z^2-k^2h^2=0\]

Der Code fasst die Koeffizienten so zusammen:

\[A=1-k^2m^2,\qquad B=-2k^2hm,\qquad C=-k^2h^2\]
\[Ax^2+Bx+z^2+C=0\]
const A = 1 - k * k * slope * slope;
const B = -2 * k * k * height * slope;
const C = -k * k * height * height;
if (A <= 0) {
  return null;
}

Wenn \(A\le 0\) ist, liegt in diesem Modell kein geschlossener elliptischer Schnitt vor. `ellipseSection` gibt dann `null` zurück.

3. Quadratische Ergänzung

Ausgehend von \(Ax^2+Bx+z^2+C=0\) isolieren wir die x-Terme und teilen durch \(A\):

\[x^2+\frac BAx=-\frac{z^2+C}{A}\]
Warum wird ergänzt? Der Term \(Bx\) verhindert, dass die Gleichung bereits um den Mittelpunkt der Ellipse zentriert ist. Wir wollen aus \(x^2+\frac BAx\) ein vollständiges Quadrat machen, denn nur dann lässt sich der Mittelpunkt direkt ablesen. Für \(x^2+px\) ist der passende Ergänzungsterm \(\left(\frac p2\right)^2\). Hier ist \(p=\frac BA\), also lautet er \(\left(\frac{B}{2A}\right)^2\). Derselbe Term wird auf beiden Seiten addiert, damit sich der Wert der Gleichung nicht verändert.

Nach dieser Addition und dem Umschreiben als Binom:

\[\left(x+\frac{B}{2A}\right)^2=\frac{B^2}{4A^2}-\frac{z^2+C}{A}\]

Nach Multiplikation mit \(A\):

\[A\left(x+\frac{B}{2A}\right)^2+z^2=\frac{B^2}{4A}-C\]

Wir definieren Mittelpunkt und rechte Seite:

\[x_c=-\frac{B}{2A},\qquad Q=\frac{B^2}{4A}-C\]

Damit erhalten wir:

\[A(x-x_c)^2+z^2=Q\]
const center = -B / (2 * A);
const rhs = (B * B) / (4 * A) - C;

4. Standardform und Halbachsen

Wir haben jetzt die Gleichung der verschobenen Schnittkurve \(A(x-x_c)^2+z^2=Q\). Durch Division der gesamten Gleichung durch \(Q\) wird die rechte Seite zu 1. Das ist die Standardform einer Ellipse: Zwei quadrierte, normierte Abstände addieren sich zu 1.

\[\frac{(x-x_c)^2}{Q/A}+\frac{z^2}{Q}=1\]

Die Halbachsen sind damit direkt:

\[a_x=\sqrt{\frac QA},\qquad a_z=\sqrt Q\]

Die Halbachsen sind die Strecken vom Mittelpunkt zum Rand der Ellipse: \(a_x\) verläuft in x-Richtung, \(a_z\) in z-Richtung. Setzt man \(z=0\), bleibt \((x-x_c)^2=Q/A\); daher ist \(a_x=\sqrt{Q/A}\). Setzt man dagegen \(x=x_c\), bleibt \(z^2=Q\); daher ist \(a_z=\sqrt Q\). 

const rhs = (B * B) / (4 * A) - C;
const ax = Math.sqrt(rhs / A);
const az = Math.sqrt(rhs);

Diese beiden Werte werden in JavaScript als ax und az verwendet.

5. Einen 3D-Punkt berechnen

Für \(t\in[0,2\pi)\) parametrisieren wir die Ellipse:

\[x(t)=x_c+a_x\cos(t),\qquad z(t)=a_z\sin(t)\]

Die dritte Koordinate kommt aus der ursprünglichen Ebenengleichung:

\[y(t)=h+m\,x(t)\]

Der räumliche Punkt lautet deshalb:

\[P(t)=\bigl(x_c+a_x\cos(t),\;h+m(x_c+a_x\cos(t)),\;a_z\sin(t)\bigr)\] 
for (let i = 0; i < sampleCount; i++) {
  const phase = (i / sampleCount) * Math.PI * 2;
  const x = center + ax * Math.cos(phase);
  const z = az * Math.sin(phase);
  const y = height + slope * x;
  points.push([x, y, z]);
}

Der Rendercode verwendet 360 Werte \(t_i=2\pi i/360\) und verbindet die Punkte mit einer geschlossenen THREE.LineLoop.

6. Zahlenbeispiel

Für \(\alpha=38^\circ\), \(h=2{,}8\) und \(k=0{,}6\) gilt:

\[m=\tan(38^\circ)\approx0{,}781286\]
\[A\approx0{,}780253,\quad B\approx-1{,}575072,\quad C=-2{,}8224\]
\[x_c\approx1{,}009334,\quad Q\approx3{,}617286\]
\[a_x\approx2{,}153147,\quad a_z\approx1{,}901917\]

Für \(t=\pi/3\), also \(\cos(t)=1/2\) und \(\sin(t)=\sqrt3/2\):

\[x\approx2{,}085907,\qquad z\approx1{,}647108\]
\[y=2{,}8+0{,}781286\cdot2{,}085907\approx4{,}429689\]

Der Punkt ist damit:

\[P(\pi/3)\approx(2{,}085907,\;4{,}429689,\;1{,}647108)\]

Kontrolle:

\[x^2+z^2\approx7{,}063972\qquad k^2y^2\approx7{,}063972\]

Außerdem gilt \(y-h-mx\approx0\). Der Punkt liegt also gleichzeitig auf Ebene und Kegelmantel.
